# KSP 插件全面测试清单 — 持续更新至 0.11.5

此清单用于持续找 Bug，不表示所有组合均已验证。每项记录：通过/失败/未测、Blender 与插件版本、资产相对路径、复现步骤、预期/实际、日志、最小 `.blend`。失败用例应加入自动回归。

## A. 安装与生命周期
- [ ] 首次安装、覆盖升级、恢复备份；版本为 0.11.5。
- [ ] 禁用/启用多次，无重复面板、残留属性或注册错误。
- [ ] 新建场景、打开旧文件、保存重开、清理孤立数据后功能正常。
- [ ] 非管理员账户、中文路径、空格路径、只读目标、取消文件选择。
- [ ] 偏好设置 GameData 路径保存；升级不重置用户设置。
- [ ] Object/Edit/Pose 模式菜单与按钮，非法模式明确阻止。

## B. 默认导入与错误恢复
- [ ] 普通静态 `.mu`、有动画 `.mu`、`.craft` 两种实例模式。
- [ ] 现有帧为负数/小数/177；场景范围/FPS/fps_base 均不变。
- [ ] 拖动时间线不自行播放；无活动 Action、播放 NLA、物理。
- [ ] 非零游标定位；导入不改旧集合名称，源根变换保留。
- [ ] 缺失单个 MODEL、多个 MODEL、全部 MODEL、未知 PART。
- [ ] 缺纹理、材质配置、GameData 目录、无法读取文件、坏文件头。
- [ ] 大小写/斜杠/扩展名差异、相对路径归一化、重复缓存加载。
- [ ] 错误报告包含 craft 零件名、配置路径、具体 MODEL 路径、原因。
- [ ] 重复导入不吞旧报告；取消/失败不残留半个模型或孤立数据。

## C. 几何与层级
- [ ] 多子网格/多材质、空材质槽、错误材质索引、有/无 UV。
- [ ] 法线/硬边/光滑、UV 接缝、顶点色、切线及手性属性。
- [ ] 无 renderer 非碰撞网格被保留且默认隐藏、单独显示。
- [ ] 旧碰撞体全部不创建；既有碰撞体不删除。
- [ ] 非均匀缩放、负缩放、深层父子、动画旋转中心。
- [ ] named Empty、无名必要节点、冗余叶节点、外部 CFG transform 名。
- [ ] 显隐不改姿态/子网格求值，不影响同型号其他实例。
- [ ] 顶点/面索引、颜色长度、损坏权重等异常数据可诊断。

## D. 骨架与蒙皮
- [ ] 无骨骼模型不造骨骼；单骨、多根骨、复杂49骨模型。
- [ ] 绑定姿态、骨骼父子、不同旋转模式、特殊字符骨名。
- [ ] 多骨权重、未权重顶点、多蒙皮网格、修改器目标正确。
- [ ] 对象约束与 PoseBone 约束目标重映射。
- [ ] 隐藏骨架仍正常蒙皮，显示切换不改变变形。
- [ ] 展开后绑定对象不指向共享缓存，其他实例姿态不变。

## E. 源片段与可靠绑定
- [ ] 单片段/多片段、同名不同动画组件、多个目标 Action 同步。
- [ ] 选根/子网格/骨架/辅助节点定位相同零件。
- [ ] 对象/骨骼/材质/灯光通道；不支持属性和缺失路径逐项列出。
- [ ] 重复节点名、重复导入、中文整理名、手工改名仍绑定正确。
- [ ] 同型号两零件不串动作、材质、灯光、骨架。
- [ ] 旧名称记录唯一迁移；重复别名不猜测，不改旧动画。
- [ ] fake user 清理、保存重开源资源/绑定/安排片段仍存在。

## F. 区间与速度
- [ ] 全片段、中间区间、小数边界、负插入帧、不同FPS/fps_base。
- [ ] 起止相等、颠倒、越界、无支持绑定、已删资源均阻止。
- [ ] 插入前静态，边界插值保持；不会复制其他片段曲线。
- [ ] 修改FPS后旧条目不重排，新条目按新有效FPS换算。
- [ ] 默认结束保持、关闭保持恢复静态、再次开启保持。
- [ ] 动画旋转/位移/缩放、布尔可见性、Light/Material 实值正确。
- [ ] 源曲线关键帧数量/句柄/插值未被裁掉或烘焙。
- [ ] 单关键时间片段提示，禁止零长度播放实例。

## G. 冲突与管理
- [ ] 无冲突直接加入；活动 Action/重叠 NLA 冲突对话框默认取消。
- [ ] 非重叠/不同通道不误报；静音轨道/solo/tweak 模式处理。
- [ ] 覆盖暂停旧条目，移除恢复 Action slot/混合/影响/静音原设置。
- [ ] 融合保留活动 Action 到 NLA；COMBINE 影响0/0.5/1。
- [ ] 面板融合↔覆盖、静音↔启用正确露出底层用户动画。
- [ ] 同目标连续两次覆盖，任意顺序移除不提前恢复。
- [ ] 完全重复安排不堆叠；不同区间/位置可分别加入。
- [ ] 选择/跳转、改名NLA、用户追加strip、手动删除strip的提示。
- [ ] 移除不删除源片段、用户strip、用户Action、其他零件播放。
- [ ] Undo/Redo：加入、展开、显隐、静音、移除、覆盖/融合。

## H. 集合实例与事务
- [ ] 轻量模式可直接选择每个零件；只展开被操作实例。
- [ ] 父变换/非均匀缩放/嵌套集合实例/重复子模型世界位置不跳。
- [ ] 材质、Light/Camera 数据和蒙皮/约束独立映射。
- [ ] 加入或展开中故障注入：对象/数据数量及原实例精确恢复。
- [ ] 连续显隐和加入动画不重复复制；其他同型号保持实例。

## I. 保存、导出与性能
- [ ] 静态、已启用、静音、部分区间、覆盖/融合分别保存重开。
- [ ] 骨架、多材质、顶点色、源动画导出 `.mu` 后重导入。
- [ ] 导出不携带预览用时间线安排和基线；有效游戏时间不偏移。
- [ ] 旧手工动画/材质/碰撞导出不回归；无骨模型导出不造骨。
- [ ] 多次导入/移除不增长无用播放Action；用户资源不误清。
- [ ] 大 craft/百零件/大量动画：导入耗时、内存、面板响应记录。
- [ ] 在真实游戏中加载导出的测试资产，检查几何、shader、部署动画。

## 建议真实资产矩阵

太阳能板、起落架、钻机（蒙皮）、降落伞（多骨）、多材质发动机、灯光、带未知脚本/粒子数据的模型；Stock/ReStock/KRE 与用户自己的模组都要覆盖。每个组合分别测直导入与 craft，实例开/关，中文命名开/关，有/无已有用户动画。

## J. 模组与索引（0.11.3）
- [ ] 有效 ModuleManager 缓存、没有缓存、存在无名块、其他损坏语法分别验证。
- [ ] PART / PROP / INTERNAL 及 UTF-8/BOM、中文、旧编码配置。
- [ ] 精确相对路径、同模组迁移、跨模组依赖缺失；不能误绑相似文件。
- [ ] 重名部件、大小写歧义、zDeprecated 归档和原始配置/补丁定义优先级。
- [ ] 确认替代规则的作用域、移除、保存重开、不同 GameData 隔离。
- [ ] 复制新模型、修改缓存、重建索引、同URL不同源/修改时间；不删除已有对象。

## K. 白模、贴图与外观（0.11.4）
- [ ] 只有碰撞组件、碰撞+MeshFilter无Renderer：不生成碰撞实体，Transform/Empty仍在。
- [ ] 真实 Renderer+碰撞组件的网格保留；COL样式名字不触发误删。
- [ ] 非碰撞无Renderer网格：直接导入、实例、展开后均默认隐藏，数据仍可单独显示。
- [ ] 骨架隐藏不停止蒙皮，Empty隐藏不改姿态；不影响同型其他零件。
- [ ] .dds/.png/.tga/.mbm、24/32bitMBM、坏文件头/截断、大小写、空格/中文路径。
- [ ] 模型本地贴图、GameData绝对资源URL、唯一共享贴图、多同名路径不能猜测。
- [ ] 缺图不绑定别的零件同名图；报告贴图索引、材质通道、查找位置及原因。
- [ ] DDS上下方向、非单位纹理scale/offset、第二UV、切线RGB/GA法线、颜色空间。
- [ ] KSP/Diffuse、Specular、Bumped、Emissive、Alpha/Cutoff Bumped、透明、自定义shader。
- [ ] 主色×贴图、发光×颜色、颜色/alpha动画；Specular的alpha不被当作透明。
- [ ] 正常RGB法线、Unity GA打包法线；同图同时作颜色与数据不串颜色空间。
- [ ] 头锥BlackAndWhite/White/Dark、助推器YellowAndWhite/Orange；与Craft选项一致。
- [ ] 同型号两个零件不同外观；材质驱动、动画、导出/保存重开仍各自独立。
- [ ] MODEL换图、多条映射、无匹配原资源、缺失新资源、重复同名/点号名字。
- [ ] GAMEOBJECTS父节点关闭时子网格也不显示，但所有网格数据仍保留。
- [ ] transformName限定换图；目标共享材质、重复节点名、未知设置记录实际影响范围。
- [ ] 未支持变体节点/脚本shader保存元数据并报告，不伪装完整支持。
- [ ] 保存后删除或移动外部贴图仍可显示内嵌资源；重载源图后角色正确。
- [ ] 实体/材质预览/渲染模式区别；按钮只改当前视图，导入不擅自切换。
- [ ] 旧场景原网格/手工材质/碰撞体不自动删除，新导入不复用旧流程缓存。

## L. 精简材质节点（0.11.5）
- [ ] 普通贴图材质仅3节点；有颜色/透明/发光/法线时按需增加，不删实际效果。
- [ ] DDS翻转、scale/offset、Specular遮罩、裁切、打包法线、材质动画仍正确。
- [ ] 相同UV合并；修改单张图参数自动拆分，不移动其他图。
- [ ] 无单位UV时采用真实活动UV；随后添加变换也有UV输入，而非全采样(0,0)。
- [ ] 拷贝/展开/保存重开后参数驱动目标仍为自己的材质，组定义无材质ID依赖。
- [ ] 整理仅改变位置/宽度/折叠状态，连接、数值和手工节点仍在。
- [ ] 精简前保存原节点备份；旧手工编辑可切回备份，不改其他材质。
- [ ] 当前Material ID、源Action、片段绑定不变，不改场景帧/FPS。
- [ ] 重复重建无悬空驱动；失败时原图不变；撤销/重做和备份保存重开。
- [ ] 节点组内部可Tab查看；渲染与前版比对；真实GUI缩放/连线/长名称可读。
